# 🏫 SchoolSync — School Management System

> "Synchronizing Education Management"

A full-stack web-based School ERP built with Python Flask + MySQL.
Designed to solve real-world school management problems.

## 👤 Built By
Abdul Wasia — BE Computer Systems Engineering, Spring 2026

## 🎯 Features
- 6 role-based dashboards (IT Admin, GR Office, FA, Teacher, Principal, Student)
- Real MySQL database with 30 relational tables
- Course system with course keys (like Google Classroom)
- Attendance marking with midnight lock + IT Admin override
- Assignment submission portal with file upload
- Subject-wise attendance for students
- FA assigns teachers to courses — teacher sees course cards
- Notification system across all roles
- Audit logging of all sensitive actions
- Email OTP for forgot password
- Principal analytics with real charts

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Backend | Python Flask |
| Database | MySQL (30 tables) |
| Frontend | HTML, CSS, JavaScript, Jinja2 |
| Auth | Session-based + bcrypt |
| Hosting | PythonAnywhere |

## 🚀 Run Locally
```bash

```
